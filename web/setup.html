2 · Set Up the Python Server

1
Install Python 3.10+

Check your version:

python3 --version

If you need to install it: brew install python@3.11 (requires Homebrew — do this before going offline).

2
Create a virtual environment and install dependencies

Run once while you still have internet:

cd ~/dev/bot-pilot/server
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

After this, the .venv folder has everything needed offline.

3
Create the .env config file 
cp ~/dev/bot-pilot/server/.env.example ~/dev/bot-pilot/server/.env

Then open server/.env in any editor and set:

SPOT_HOSTNAME192.168.80.3
SPOT_USERNAMEuser
SPOT_PASSWORDffha0creh9fc

The finished file looks like this:

SPOT_HOSTNAME=192.168.80.3
SPOT_USERNAME=user
SPOT_PASSWORD=ffha0creh9fc

3 · First Run

1
Connect your Mac to Spot's WiFi

See section 1 above. Confirm ping 192.168.80.3 succeeds.

2
Start the server 
cd ~/dev/bot-pilot/server
source .venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000

You should see:

INFO  Connecting to Spot at 192.168.80.3
INFO  Authenticated and time-synced
INFO  Robot standing — starting command loop
INFO  Uvicorn running on http://0.0.0.0:8000
3
Open the controller

Open http://localhost:8000 in Safari or Chrome. The green dot in the top-left confirms the WebSocket is live.

Keep the terminal window open — closing it shuts down the server and the robot will stop (velocity command timeout).
4
Power on the robot first

The tablet app or physical button must have powered the robot on before you start the server. The server calls robot.power_on() and blocking_stand() on startup — the robot will stand up automatically.

Clear the area around the robot before running the server. It will stand as soon as authentication succeeds.

5 · Troubleshooting

!
Server fails: "lease already held"

Another client (the tablet app, previous session) has the lease. Release it from the tablet app, or restart the robot.

!
Robot doesn't stand / "Motor power failed"

The robot must be powered on and in a safe starting position (on the ground, legs tucked). Power it on via the physical button before running the server.

!
Controller page shows disconnected dot

The server isn't running or the browser is on the wrong network. Confirm the terminal shows the uvicorn line and that you're connected to Spot's WiFi (not your home network).

!
Body pose not maintaining while walking

Confirm you're in Walk mode (green badge). In Stand mode, body pose uses a different command path. The sliders affect both modes but the walk-with-pose feature requires Walk mode to be active.
